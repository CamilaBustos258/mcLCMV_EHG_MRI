# data/

Pipeline outputs and demo assets live here.  Raw source data (MRI + EHG) is
stored **outside** this repository in a shared folder so it is never accidentally
committed to the public repo.

## Sourcedata (external — not in this repo)

Raw inputs are stored at the path defined in `data_config.yaml` at the project
root (gitignored).  Create that file on your machine:

```yaml
# data_config.yaml  ← lives at project root, gitignored
sourcedata_root: /absolute/path/to/your/shared/sourcedata
```

Or set the environment variable instead:

```bash
export MCLCMV_SOURCEDATA=/absolute/path/to/your/shared/sourcedata
```

Expected structure inside sourcedata:

```
sourcedata/
└── sub-XX/ses-YYYYMMDD/
    ├── mri/
    │   ├── T1w.nii.gz
    │   ├── label-uterus_mask.nii.gz
    │   ├── label-bladder_mask.nii.gz
    │   └── label-electrodes_mask.nii.gz
    └── ehg/
        ├── sub-XX_ses-YYYYMMDD.vhdr
        ├── sub-XX_ses-YYYYMMDD.vmrk
        └── sub-XX_ses-YYYYMMDD.eeg
```

## Derivatives (this repo, gitignored)

Generated by the pipeline — never committed, always reproducible from sourcedata.

```
data/
└── derivatives/
    ├── synced/          # preprocessed EHG + surfaces + electrode coords
    │   └── sub-XX/ses-YYYYMMDD/
    │       ├── session_data.npz
    │       └── meta.json
    └── analysis/        # LCMV beamformer results
        └── sub-XX/ses-YYYYMMDD/
            ├── results_light.npz
            ├── results_full.pkl
            └── config.json
```

## Demo assets

`data/demo/` contains pre-computed figures and metrics from one example session
(sub-06, ses-20250828).  These are tracked in git as illustrative outputs.

Subject naming follows BIDS convention: `sub-XX` (two-digit zero-padded IDs),
`ses-YYYYMMDD`.
